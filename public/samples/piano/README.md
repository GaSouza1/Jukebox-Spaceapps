# Piano samples

Subset (C2–C6, every minor third) of the **Salamander Grand Piano V3** by Alexander Holm,
licensed under [CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/).
MP3 encodings taken from the Tone.js audio repository (`tonejs.github.io/audio/salamander`).
Hosted locally so playback doesn't depend on a third-party CDN.
